# 42 Documentation

> Learning computer science by understanding what we build, why we build it, and how it works.

42 과제를 진행하며 학습한 개념과 기술을 정리하는 개인 문서입니다.

과제를 단순히 완성하는 것보다, 프로젝트에서 사용하는 기술이 **왜 필요한지**, **어떻게 동작하는지**, 그리고 **서로 어떻게 연결되는지** 이해하는 것을 목표로 합니다.

## How I Learn

각 프로젝트는 다음과 같은 흐름으로 학습하고 정리합니다.

```text
Project Subject
      ↓
What are we building?
      ↓
Why do we need it?
      ↓
Core Concepts
      ↓
How does it work?
      ↓
Implementation
      ↓
Verification & Review
```

과제의 요구사항을 먼저 파악하고, 구현에 필요한 개념과 기술을 학습한 뒤 실제 구현과 연결합니다.

명령어나 코드를 단순히 기록하기보다는 **각 요소의 역할과 전체 시스템 안에서의 연결 관계**를 이해하는 데 초점을 둡니다.
